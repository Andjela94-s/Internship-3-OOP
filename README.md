# Internship-3-OOP
Hotel app in C# that can add and check guests, rooms, reservations and staff.

Content:
-Program.cs
-Classes: Entity, Guest, Room, Reservation, Employee, Shift
-Enums: RoomCategory, ReservationStatus, EmployeePosition, EmployeeGender, ShiftType
-Services: HotelManager

How to use:
1.)In Visual Studio 2026 create a project "Console App" in C#.
2.)Create maps in project: Classes, Enums and Services.
3.)Copy the .cs file.
4.)Replace the default Program.cs with Program.cs from this project.
5.)Start the project by pressing debug or (Ctrl + F5).

Attention:
This app doesn't use secure heshing for password, but rather saves it as a string.
